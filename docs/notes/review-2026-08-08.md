# Pre-commit adversarial review — 2026-08-08

Five parallel reviewers (money/web, membership-py, pipeline/ledger,
web-app, automation wiring) swept the uncommitted M0–M4b build; 56
findings, hand-verified. The fixes that shipped in the same commit:

## Money & members (the sacred paths)

- Stripe webhook: idempotency claim is now RELEASED on processing
  failure (retry can reprocess — a paid event can no longer be lost);
  grant requires `payment_status='paid'` + handles
  `async_payment_succeeded/failed`; **partial refunds no longer revoke**
  (full-refund flag checked); sessions without our `metadata.plan`
  marker are ignored (Payment Links can't mint passes).
- Publish fan-out is **idempotent**: send_log consulted before every
  channel/member send, per-member isolation — a mid-fan-out failure
  resumes instead of double-posting/double-mailing.
- Member audience is **snapshotted at reserve time** — a signup mid-run
  can't push sends past the reserved upper bound.
- Channel removal is a retryable queue (`members_needing_removal`:
  lapsed+refunded with a bound telegram id; id NULLed only on success);
  per-member isolation; permanent 4xx drains. Removal is metered at its
  true cost (2 HTTP calls).
- Reminders: T-30 floored at >7 days out; days-left computed from
  member_until (copy can never lie); per-member isolation; canonical
  timestamp format in the dedup query.
- Unsubscribe GETs no longer execute (scanner prefetch was silently
  suppressing recipients) — GET renders a confirm form; POST remains
  the RFC 8058 one-click. /api/subscribe no longer clears suppressions
  (unauthenticated resubscribe attack).
- tg_bind deep link: status checked BEFORE consuming (a lapsed member's
  tap no longer burns their only link); defensive unban before invite
  (a crashed ban→unban can't lock a renewed member out); honest failure
  message + `tg_invite_failed` event instead of "llegará en breve".
- Founding price: `FOUNDING_OPEN=false` env flip closes the window.
- Suppression contract documented: bulk sends gated, solicited
  transactional access mail (welcome/magic link) exempt by design.

## Pipeline & ledger

- resend per_search_cap removed (the fan-out grows with the audience —
  the fixed cap would have silently halted the ENTIRE pipeline at ~20
  members); reserve refusal on a scheduled run now pages via ntfy and
  exits degraded instead of a green no-op.
- Self-imposed monthly pools (anthropic/resend) re-anchor at month turn
  — an exhausted draft budget no longer halts everything forever.
- Guardrails bounded to the cooldown window (a route is no longer muted
  FOREVER around an old deal price); dead rows (expired/stranded) no
  longer dedup-kill routes; missing-key aborts mark the deal expired.
- Baseline P10 uses inclusive quantiles (exclusive extrapolated below
  the min at n=8 — a matured route could never alert again).
- baseline_context wording now matches the gate that produced the
  number (route history vs class cross-section — D7 honesty).
- Heartbeat during interactive approval (lease can't expire mid-run);
  publish-only dispatch retries the lease for ~5 min; receipt compares
  reserved vs RAW spend (settle clamps made the old check unfalsifiable);
  watchlist 1×/day gate requires successful calls, not just charged ones.

## Flagged, deliberately NOT changed (decisions for Carlos)

1. **Baseline selection bias** (D2 semantics): verified observations
   come only from deal verifications, so a route's "normal" learns from
   its cheap tail. The audits + D2's reversal triggers watch it; the
   real remedy — periodic verification of NORMAL fares across the
   watchlist — is a paid-call spend decision.
2. Free-list unsub tokens stored raw (capability tokens; hashing them
   breaks the Python sender's URL embedding — accepted at this threat
   model).
3. Magic-link timing side-channel (member vs non-member response time)
   — accepted at this scale; Vercel waitUntil is the fix if it matters.
4. Digest week window still misses deals approved after a SENT Sunday
   digest (draft-refresh covers the pre-send gap).
