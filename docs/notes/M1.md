# M1 — Four origins, real detector, ops queue (2026-08-08)

## Built

- **Four origins** (D0): `routes/vuelazo.yaml` origins = MAD/BCN/VLC/ALC;
  the sweep loops all four (8 aviasales calls/run at 2 months each).
- **Watchlist** (~38 dests × 4 origins): `watchlist:` in the YAML;
  refreshed once per day via one cached `latest_prices` call per route
  (the 1×/day gate reads today's spend_events — the sweep-cooldown
  pattern). Routes surface into `routes_watchlist` organically.
- **Baselines + incremental activation** (D2): `lib/baselines.py` —
  trailing-60d distribution of VERIFIED observations per route;
  `min_observations: 8`. `gate_candidates` now tries the per-route
  percentile gate first (price ≤ P10 AND ≥25% below median AND saving ≥
  floor) and falls back to the day-one cross-section for immature
  routes. Every successful verification inserts a verified
  `fare_observations` row, so history accumulates from real spend.
- **Queue mode**: `run_deals.py --queue` (cron) drafts into status
  'queued' — no console; `--publish-only` fans out approved deals (the
  /ops approve button dispatches it via workflow_dispatch). Approvals
  also get swept up by the next cron run, so a missing GH token only
  slows fan-out, never loses it.
- **Ops deal queue UI**: `/ops` "Deal queue · vuelazo" panel —
  `web/src/lib/deals.ts` (reads), `api/ops/deals/[id]` (PATCH
  approve/reject/edit with CAS status guards), `components/ops/
  DealQueue.tsx` (cards: route, price, −%, normal, confidence,
  verificar link, sparkline from fare_observations, draft text,
  approve + free-pick flag / edit / reject with one-tap reason).
  Verified in the browser against live Turso data.
- **Mistake fast lane**: ntfy push (`lib/pushes.py`) fires when a
  mistake-class candidate is held; a queue-summary push tells Carlos
  there are cards to approve.
- **Cron**: `.github/workflows/deals.yml` — 3×/day (05:41, 11:41,
  17:41 UTC) `run_deals.py --queue`, plus `publish_only` dispatch input.
- **Audits**: `scripts/week1_audits.py` writes the week-1 report (cache
  freshness via found_at, insights coverage, skyscanner-probe verdict
  [parked: PerimeterX], queue discipline vs cap, VLC/ALC excellent-deal
  rate for the D0b week-8 checkpoint).
- `deals.free_pick` column added via the deals_db migration ladder
  (prod table already existed).
