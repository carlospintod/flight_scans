# M4a + M4b — Public site & SEO pages (2026-08-08)

## The structural decision: two root layouts, one app

Next.js route groups split the app into `(tracker)` (the existing
phosphor-dark flight_scans site, untouched URLs) and `(vuelazo)` (the
new brand). Vuelazo gets its own ROOT layout: D7's editorial
data-design — warm paper `#faf6ef`, near-black ink, ONE amber signal
(`--color-vz-*` tokens in globals.css), Fraunces display + Inter text
via next/font. When vuelazo.es points at the Vercel app, a host-based
rewrite in `src/proxy.ts` maps `/` → `/vuelazo` for that host (one-line
change, noted below); until then the landing lives at `/vuelazo`.

## M4a — pages (all built, browser-verified against live Turso)

- `/vuelazo` landing: hook, honest cumulative savings counter
  (SUM(abs_saving) of published), latest 3 delayed deals, free signup
  (`/api/subscribe`), medimos/verificamos/avisamos, founder-story block
  (Nairobi), membership CTA.
- `/vuelazos` archive: 24h-delayed published deals, per-airport filter
  (`?desde=VLC`), full draft text per deal.
- `/vuelos-baratos/[origin]` hubs ×4 (SSG): live cheapest-now grid from
  fare_observations (with honest "orientativos hasta verificar" copy),
  verified deals from that origin, signup.
- `/unete` checkout (M2 backend), `/gracias`, `/cuenta` — restyled to
  the paper theme.
- Legal: `/aviso-legal`, `/privacidad`, `/condiciones` — **drafts with
  visible "pendiente de revisión (gestoría)" banners**; the 14-day
  guarantee is framed as the statutory withdrawal right honored (D5).

## M4b — gated SEO route pages

- `/vuelos-baratos/[origin]/[dest]` (ISR daily = "SSG nightly"):
  data-derived only — price-history inline SVG (no client JS), provable
  "precio normal" (verified median when mature, cached median labeled
  "provisional" otherwise), recent best fares, data-derived best-month
  note, alerts CTA. 404 when the route has zero measurements.
- **Quality gate = the detector's own bar** (D6): `seo_pages.status`
  becomes 'published' only at ≥ min_observations (8) verified obs in
  60d; everything else renders with `robots: noindex`. Verified live:
  today's run gated 32 routes → 0 published, 32 noindex (correct at
  cold start).
- Claude intros: `templates/seo_intro_es.md` v1 (anti-template voice
  rules) + `scripts/gen_seo_intros.py` — once per published route,
  quarterly refresh, ledger-metered, defers gracefully without the API
  key (pages run on data blocks meanwhile). `build_user_prompt` now
  derives required fields from each template's own placeholders.
- `sitemap.xml`: static pages + hubs + ONLY published seo_pages rows.
- `seo.yml` nightly cron: gate + intros + ISR revalidate ping.
