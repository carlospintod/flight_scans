# M3 — Publishing polish (2026-08-08)

## Built

- **Digest assembler** (`lib/digest.py` + `scripts/run_digest.py` +
  `digest.yml` Sunday cron): self-assembles from the week's APPROVED
  deals (best score first) — pure composition of the already-approved
  Claude drafts, no new API spend. Idempotent per week (UNIQUE
  week_start), lifecycle draft → approved → sent. Cron assembles + ntfy
  "digest listo"; sending is an explicit dispatch with send=true (the
  one Sunday review, D3) or an interactive local run. Recipients:
  subscribers (active − suppressions) + owner; per-subscriber one-click
  List-Unsubscribe token; ledger-reserved per recipient.
- **Free list**: `subscribers` table (+`unsub_token`);
  `POST /api/subscribe` (landing form target, rate-limited, resubscribe
  clears the suppression) and `/api/subscribe/unsubscribe` (RFC 8058).
- **T+24h free-channel automation** (`dg.free_picks_due` wired into
  run_deals step 0a): published free-pick deals older than 24h whose
  send_log has no tg_public row post to `TELEGRAM_PUBLIC_CHANNEL_ID`
  with the honest receipts line ("los miembros lo recibieron hace 24
  horas"). The site archive needs no extra step — it reads published
  deals with the same 24h delay (M4a).
- **Deal-card renderer** (`lib/dealcard.py` + `scripts/render_cards.py`):
  1080×1350 PNG, D7 editorial tokens (warm paper #FAF6EF, near-black
  ink, ONE amber accent reserved for the price, serif display + sans
  text, hand-drawn route arrow — serif faces lack U+2192), price-history
  sparkline with honest empty state ("histórico en construcción" — never
  fake data). Font ladder prefers vendored `assets/fonts/` (drop in
  Fraunces/Inter OFL files to upgrade), falls back to Georgia/Segoe
  (Windows) or DejaVu (CI).
- **Deliverability test**: procedure + pass bar + Brevo fallback +
  warm-up plan in `docs/notes/deliverability-test.md` (execution needs
  the Resend key + vuelazo.es DNS — M4a).

## Choices

- Digest WITHOUT a new Claude call: the deal texts are already
  Claude-written and human-approved; composition keeps the digest
  truthful and free. (A digest-intro template can come later as a
  template commit.)
- Free-pick flag lives on approve (M1 UI checkbox) — the approver
  decides at the moment of judgment, per spec.
- Cards are Pillow, not headless-browser screenshots: zero new infra,
  boring, testable offline; brand fonts are a vendored-assets upgrade,
  not a code change.
